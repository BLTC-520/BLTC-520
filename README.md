## 🚀 Featured Projects

### 🦄 [Time-TokenAIzer](https://github.com/BLTC-520/time-tokenAIzer)
`Solidity` · `Foundry` · `Uniswap v4` · `Chainlink` · `Next.js` · `Wagmi/viem`

Wallet-connected marketplace for **redeemable professional time** — creators publish provider inventory, buyers book with ERC-20 **TIME** credits. Adds a **Uniswap v4 TIME/USDC** liquidity layer whose **TimePoolHook** validates booking-aware swap intent through hook data, with EIP-712 signed quotes, slot locking, replay protection, and burn-on-booking accounting handled in **BookingManager**. Foundry-tested across hook, quote, and inventory failure paths.

### 🏆 [SnapRoom](https://github.com/BLTC-520/snaproom) &nbsp;·&nbsp; 🥈 2nd Place — Ralphthon @SG 2026
`React` · `TypeScript` · `Three.js / R3F` · `World Labs` · `Fal AI` · `Expo`

Turns a single floor plan, sketch, or room photo into a **fully walkable 3D world**. Generates explorable **Gaussian-splat** environments through the World Labs API (rendered in real time with the Spark renderer over Three.js / R3F), layers an **AI semantic-label system** that raycasts Gemini Vision detections back into 3D, adds AI-generated furniture meshes + ambient sound via Fal AI, and ships a companion **React Native AR viewer** launched from a scanned QR handoff and driven by the phone's fused motion sensors.

### 🧪 [DataForge](https://github.com/BLTC-520/AIE2026-DataForge) &nbsp;·&nbsp; AI Engineer SG 2026
`Next.js` · `Convex` · `GPT-5.5` · `Fal AI` · `Zod` · `Tailwind`

Turns messy labeled image datasets into **training-ready assets** — surfacing missing labels, likely mislabels, duplicates, and class imbalance before training. A dashboard workflow handles baseline evaluation, human-in-the-loop label/duplicate review, class-balancing plans, re-evaluation, and export of a cleaned dataset manifest with before/after quality metrics — all orchestrated in real time on Convex with multimodal LLM-assisted auditing.

### 🛰️ [Solana-Online-Blog-dApp](https://github.com/BLTC-520/Solana-Online-Blog-dApp)
`Rust` · `Anchor` · `Solana`

On-chain blogging dApp built on the **Solana / Anchor** program model — my first deep dive into Solana program development (School of Solana, Season 8).
